## 📂 Projects

### 1. AWS Auto Scaling & Load Balancing Project

Built and tested a scalable web infrastructure on AWS using Linux EC2 instances.

**Technologies & Services:**
- Amazon EC2
- Amazon Linux
- Custom AMI
- Launch Template
- Auto Scaling Group (ASG)
- Application Load Balancer (ALB)
- Target Group
- CloudWatch Metrics
- Linux Stress Utility

**What I Practically Tested:**
- CPU load generation using `stress`
- Automatic Scale-Out during increased workload
- Automatic Scale-In after workload decreased
- EC2 capacity management using Auto Scaling
- Load balancing across healthy EC2 instances
- Auto Scaling self-healing behavior
